# Local 3D models (optional, not committed)

Put GLB files here to replace the built in generic models in the 3D view:
`rack.glb`, `ups.glb`, `tx.glb`, `gen.glb`, `chl.glb`, `cdu.glb`.

- Y up, metres. The model is scaled uniformly to fit the footprint and placed on the floor.
- Only geometry and base colours are used. Textures are ignored.
- Convert OpenUSD to GLB yourself (for example with Blender or `usd2gltf`).
- Check the licence of every asset before use. NVIDIA DSX sample data is licensed for evaluation only and must not be committed to this repository.
